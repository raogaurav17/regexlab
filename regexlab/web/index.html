How it works

Grammar (recursive descent; precedence: repetition > concatenation > union):

regex  → term ( '|' term )*
term   → factor*                (empty term = ε)
factor → atom ( '*' | '+' | '?' )*
atom   → CHAR | '(' regex ')'
  • Thompson's construction builds an ε-NFA with one start and one accept state; |NFA| = O(m) for a regex of length m.
  • Subset construction turns each reachable set of NFA states (closed under ε) into one DFA state. Worst case 2n states.
  • Hopcroft's algorithm refines {accepting, non-accepting} until no block splits, always re-queuing the smaller half. With inverse-transition lists it runs in O(|Σ| · n log n); this implementation scans for pre-images for clarity (O(|Σ| · n²) worst case). A hidden dead state keeps the DFA total and is omitted from the drawing.
  • Every run is cross-checked against Python's own re engine.
